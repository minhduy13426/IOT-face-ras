# Admin Dashboard & API - Hệ thống Điểm danh AI

> [!IMPORTANT]
> Đây là hướng dẫn riêng cho thành phần Admin. Để xem hướng dẫn toàn bộ hệ thống (bao gồm cả Raspberry Pi), hãy xem file **[README.md ở thư mục gốc](../../README.md)**.

## 🚀 Cài đặt nhanh (Thành phần Admin)
1. **Cấu hình**: Sửa file `.env`.
2. **Cài đặt**: `pip install -r requirements.txt`.
3. **Chạy**: `uvicorn main:app --host 0.0.0.0 --port 8000`.

---
*Xem hướng dẫn đầy đủ tại thư mục gốc của đồ án.*
